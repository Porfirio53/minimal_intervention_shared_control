# 基于因果对齐与概率安全约束的远程驾驶最小介入共享控制方法

## 引言

远程驾驶为自动驾驶系统处理超出其运行设计域的复杂场景提供了一种重要的人在回路解决方案。通过将感知信息传输至远端驾驶员，并将驾驶员控制指令回传至车辆，远程驾驶能够利用人的场景理解、推理与异常处置能力补充车端自动系统的能力边界。然而，远程闭环天然受到通信网络的影响。上下行链路中的传输时延、抖动与丢包不仅会降低驾驶员获得环境信息的实时性，也会使车辆端接收到的人工控制指令对应于历史观测状态，从而形成显著的状态—控制时间错位。已有研究表明，通信时延会恶化远程车辆的轨迹跟踪与操纵稳定性，并可能诱发过度修正、振荡以及驾驶负荷上升等问题[1]–[4]。因此，在不能假设网络始终具有低时延和高可靠性的条件下，仅依赖纯人工远程驾驶难以同时满足安全性、操纵性与任务效率要求。

共享控制通过同时保留人工驾驶员和车端自主系统的控制作用，为缓解上述问题提供了另一条技术路径。传统共享控制通常将人工输入与自主控制输入进行加权融合，并根据驾驶风险、驾驶员状态、人机冲突或系统置信度调节控制权。近年来，相关研究已从静态权重逐步发展到预测风险、优化分配以及时延感知仲裁。Liang等[5]将周围交通参与者的未来运动用于预测风险场构造；Brecht和Diermeyer[6]在远程驾驶场景中引入动态环境风险评估；Chen等[7]进一步利用控制屏障函数和控制李雅普诺夫函数构造二次规划，实现满足安全约束的动态控制权分配。针对通信时延，Güleçyüz等[4]基于人工与自主系统置信度设计时延感知仲裁；Wang等[2]通过预测自主轨迹提前触发接管请求，并利用驾驶员意图轨迹重构延迟人工输入；Liu等[1]则明确区分驾驶员意图轨迹与时延作用下的执行轨迹，通过因果时间对齐恢复观测—命令对应关系，并基于通信时延和人机方向一致性调节共享控制比例。由此可见，“意图预测+动态权重”“风险指标+经验映射”以及“共享控制+控制屏障函数”本身均已具有较充分的研究基础，不宜再作为独立创新进行宽泛声称。

尽管如此，现有工作之间仍存在一个尚未充分解决的交叉问题。首先，远程驾驶中的人工控制输入具有明确的时间语义：车辆当前收到的命令通常是驾驶员针对历史画面形成的决策，因此瞬时输入差或当前方向一致性并不必然等价于当前的人机意图冲突。其次，预测风险、控制权优化和最小介入思想虽然均已有研究[5]–[9]，但在具有通信时延的持续共享控制中，如何将因果对齐后的驾驶员多步意图、车端自主规划、实际共享执行轨迹和动态障碍预测置于同一未来时间基准下，并由未来安全约束直接确定“哪些时刻必须增加自主权、增加多少自主权”，仍缺乏清晰且可解释的统一建模。最后，预测层不可避免地受到意图建模、感知和运动预测误差影响，因此协同层的安全约束不能替代独立的执行级安全机制；与此同时，将意图预测方差直接等同于车辆执行误差并写入硬安全边界也缺乏一致的概率语义。

基于上述认识，本文研究具有通信时延的低速远程移动车辆持续共享控制问题。本文不重新设计新的深度意图预测网络，也不将控制屏障函数本身作为新的理论类别，而是围绕“在驾驶员信息陈旧且未来行为存在分歧时，车端应在何时、以多大程度介入”这一核心问题，构建因果时间对齐的预测控制权可行域，并在该可行域内求解最低必要自主介入。为避免上层预测失配直接破坏实际安全，进一步在车端执行入口设置与意图预测器解耦的信息年龄与不确定性感知安全过滤器。

本文的主要贡献概括如下：

1. 构建一种具有因果时间基准和执行语义的远程共享驾驶预测控制权可行域。本文区分驾驶员反事实意图轨迹、车端自主规划轨迹、给定共享策略后的实际执行轨迹以及动态障碍物轨迹，在统一有限预测时域中分别描述未来人机空间分歧、意图模糊度和概率安全裕量，并进一步建立安全裕量对各预测步控制权的敏感度，从而避免将瞬时控制冲突或意图不确定性直接等同于执行风险。

2. 提出一种具有显式自主介入预算的两级控制权序列优化方法。在固定候选输入和局部线性化条件下，首先在未来安全可行域内最小化累计自主控制权，再在不超过最优介入预算的条件下优化控制权平滑性、人工意图保持和任务性能。该构造不依赖预设的风险—权重映射函数，并使“最小必要自主介入”成为可直接计算和评价的优化性质。

3. 建立一个独立于人工意图预测器的执行安全契约。安全过滤器仅使用车端实际可获得的相对状态、信息年龄、状态估计与局部执行误差界，通过信息年龄传播构造相对状态置信集合，并以离散鲁棒控制屏障约束最小修正共享名义命令。在误差置信事件有效、初始安全、约束持续可行且命令按模型执行的条件下，可得到真实安全集合的离散前向不变性以及有限时域概率无碰撞下界。该层作为整体方法的理论和工程安全保障，而不将已有的不确定性控制屏障函数思想重新包装为新的屏障函数类别。

## 相关工作

### 通信时延下的远程驾驶与共享自主

通信时延是远程驾驶和遥操作系统中的基础问题。Bellamri等[3]针对自动地面车辆同时考虑车辆到驾驶端的前向时延和驾驶端到车辆的反向时延，通过预测显示补偿陈旧状态，并针对不能被完全预测或补偿的时延设计与时延相关的车速限制。这类工作说明，时延不仅影响信号重构，也会改变车辆能够安全运行的动态范围。与单纯信号补偿不同，本文关注的是在时延已经造成驾驶员信息陈旧的条件下，人工与自主系统如何持续协同，因此仅将普通时间戳和信息年龄作为系统输入，而不依赖特定的延迟补偿预测器。

近期研究开始将通信时延显式引入共享自主与意图推断。Güleçyüz等[4]考虑延迟反馈对驾驶员决策和置信度的影响，并通过人工与自主系统置信度设计动态仲裁，同时利用无源性方法维持双边遥操作稳定性。Liu等[1]进一步指出，在双向通信时延下，当前到达车辆端的人工命令是针对历史观测状态生成的，若直接以当前车辆状态与该命令构造训练样本，将破坏观测与动作之间的因果对应关系。该研究通过时间对齐构造概率意图轨迹，并采用人工势场产生辅助控制，最终根据人机方向一致性与归一化时延进行仲裁，其代表性形式为

$$
a=\max\!\left\{\frac{(u^H)^\top u^A}{\|u^H\|\|u^A\|},0\right\},\qquad
\alpha=a^{1-\kappa\bar\tau}.
\tag{1}
$$

式中，$a$表示人工与自主控制方向的一致程度，$\bar\tau$为归一化时延。Wang等[2]则针对被动接管过程预测自主车辆未来轨迹以提前触发接管请求，并预测驾驶员意图轨迹、利用模型预测控制重构延迟人工输入，再依据风险与时延影响量递推控制权。上述研究已经覆盖了“通信时延—意图预测—动态仲裁”的主要技术链。因此，本文不把时间对齐或概率意图预测作为新的算法贡献，而是在其时间语义基础上进一步研究由未来安全可行性反求控制权序列的问题。

### 预测风险与动态控制权分配

共享驾驶中的控制权分配经历了从固定权重、规则函数到预测与优化分配的发展。Liang等[5]利用数字孪生和周车运动预测建立预测风险场，并在共享转向中兼顾驾驶风险与驾驶员输入保持；Brecht和Diermeyer[6]面向自动驾驶车辆远程操作，将动态交通参与者风险和碰撞时间等指标引入共享控制。这些研究表明，单纯依赖当前时刻风险可能无法及时反映未来交通演化，但“预测风险+最小干预”的总体思想本身已经存在。

另一方面，优化式控制权分配已成为重要研究方向。Chen等[7]利用控制屏障函数和控制李雅普诺夫函数构造凸二次规划，并通过优化权重变化率获得平滑的控制权过渡；其后续研究[8]进一步将纵向与横向控制权置于统一车辆模型中，并考虑传感器不确定性和环境鲁棒安全约束。因此，“将控制权设为优化变量”或“使用二次规划实现平滑权重”并非本文独有。Chaubey等[9]提出的最小介入共享控制还进一步利用控制不变集，在非凸约束下以最小方式修正用户输入并保证约束满足。这些工作要求本文将创新范围进一步收缩到远程通信时延场景中的具体数学结构：本文关心的不是是否能够优化权重，而是如何将因果对齐的多步人工意图、未来障碍风险和共享执行轨迹转化为控制权可行域，并优先求解满足全部未来约束所需的最低累计自主权预算。

### 安全约束共享控制

控制屏障函数已广泛用于安全关键控制，并逐渐应用于共享控制。Dallas等[10]利用控制屏障函数限制车辆进入不可恢复的动态区域；Xu等[11]在辅助移动机器人共享导航中将用户偏好、模型预测控制和动态控制屏障约束结合。对于环境和预测不确定性，Hamdipoor等[14]研究了动态环境不确定性下的环境鲁棒控制屏障函数，并讨论了基于二次规划的最小修正；Molnar等[13]进一步针对动态环境中的输入时延构造安全关键控制方法，通过预测延迟区间内系统与环境演化处理输入时延及预测误差。Busellato等[12]则将概率运动预测不确定性显式用于预测控制屏障函数，通过预测协方差调整安全边界。针对输入时延安全控制，Kim等[15]进一步研究了通过在线时延估计降低安全控制保守性的思路，进一步说明时延鲁棒安全控制本身已形成独立研究脉络。

因此，本文最后安全层的定位不是提出“新的时延控制屏障函数”，而是建立与上层意图预测和控制权分配解耦的执行安全契约。其关键建模原则是严格区分驾驶员信息年龄$\tau^H$与安全过滤器实际使用的安全信息年龄$\tau^S$，并严格区分驾驶员意图分布$\Sigma^H$与给定实际控制策略后的执行状态误差。只有与实际相对状态和执行过程具有一致物理语义的不确定性才进入硬安全约束，从而使安全结论不依赖特定人工意图预测模型。

## 问题建模

### 系统架构与通信时间语义

考虑由远程驾驶员、双向通信网络、车端自主控制器、共享控制器以及车辆执行系统组成的远程共享驾驶架构。远程驾驶员根据接收到的视频或状态反馈形成控制命令，车端自主控制器根据本地感知和局部规划产生自主候选输入。设第$m$条人工命令为$c_m$，该命令所依据画面的采集时刻为$s_m$，驾驶端生成命令的时刻为$g_m$，车辆端接收命令的时刻为$r_m$。在车端实际控制时刻$t_k$，人工上行时延和该人工命令所依据状态的信息年龄定义为

$$
\tau_m^\uparrow=r_m-g_m,\qquad
\tau_k^H=t_k-s_m=(t_k-r_m)+\tau_m^\uparrow+(g_m-s_m).
\tag{2}
$$

其中，$g_m-s_m$不仅可能包含下行通信时延，还可能包含解码、排队、显示和驾驶员响应相关间隔。因此，在能够获得原始帧时间戳或帧号时，人工命令应与$\hat x(s_m)$进行因果配对，而不能与当前状态$\hat x(t_k)$直接配对。本文将由此形成的时间对齐历史记为$\mathcal H_k$。需要强调的是，$\tau_k^H$描述驾驶员决策所依据信息的陈旧程度，而安全过滤器对障碍相对状态实际使用的数据年龄另记为$\tau^S_{j,k}$。当安全过滤器部署于车端并直接使用本地传感器时，$\tau^S_{j,k}$通常显著小于$\tau_k^H$，二者不能互相替代。

### 主要符号与变量

为避免远程驾驶中的时间语义、意图不确定性与执行不确定性相互混淆，本文采用如下统一符号。除特别说明外，下标$k$对应车辆端真实执行控制步，下标$i$对应有限预测时域中的预测步。

| 符号 | 含义及单位 |
|---|---|
| $k,T_s$ | 车辆端实际控制步及采样周期，$T_s$单位为秒 |
| $i,N,\Delta$ | 预测步、预测长度与预测离散间隔 |
| $x=(p_x,p_y,\psi)$ | 低速差速车辆位姿，位置单位为米，航向单位为弧度 |
| $u=(v,\omega)$ | 速度层输入，分别为线速度与角速度 |
| $c_m,s_m,g_m,r_m$ | 第$m$条驾驶员命令、所依据画面采集时刻、命令生成时刻及车端接收时刻 |
| $\tau_m^\uparrow,\tau_k^H$ | 人工命令上行时延与驾驶员所依据信息年龄 |
| $\tau_{j,k}^S$ | 安全过滤器对第$j$个相对状态所使用信息的年龄 |
| $\alpha_{i|k}$ | 自主控制权，$0$表示人工候选输入，$1$表示自主候选输入 |
| $u^H_{i|k},u^A_{i|k}$ | 人工候选控制与自主候选控制 |
| $u_k^N,u_k^F$ | 共享名义命令与安全过滤后的最终执行命令 |
| $P_i^H\sim(\mu_i^H,\Sigma_i^H)$ | 驾驶员反事实意图位置分布 |
| $p_i^A$ | 本地自动驾驶规划名义位置 |
| $P_i^E\sim(\bar p_i,\Sigma_i^E)$ | 给定共享控制策略后的车辆执行位置分布 |
| $O_{j,i}\sim(\mu_{j,i}^O,\Sigma_{j,i}^O)$ | 第$j$个动态障碍物的未来位置分布 |
| $R_j$ | 自车与障碍物包围半径之和及基础安全间距，单位为米 |
| $\varepsilon_{j,i}$ | 上层预测机会约束的风险预算 |
| $\delta_{j,k}$ | 安全过滤置信事件的失败概率预算 |
| $n_{j,i}$ | 从障碍物指向车辆的固定单位分离法向量 |
| $\mathcal F_k$ | 时刻$k$车辆端可获得的信息集合 |

### 车辆模型与共享控制变量

为突出远程共享控制本身并控制理论复杂度，本文以低速差速移动车辆为研究对象。车辆状态定义为$x_k=(p_{x,k},p_{y,k},\psi_k)$，速度层输入为$u_k=(v_k,\omega_k)$，其离散运动学写为

$$
x_{k+1}=f_{T_s}(x_k,u_k)+w_k,
\qquad
\begin{bmatrix}p_{x,k+1}\\p_{y,k+1}\\\psi_{k+1}\end{bmatrix}
=\begin{bmatrix}p_{x,k}+T_sv_k\cos\psi_k\\p_{y,k}+T_sv_k\sin\psi_k\\\psi_k+T_s\omega_k\end{bmatrix}+w_k.
\tag{3}
$$

其中，$T_s$为车辆端实际控制周期，$w_k$包含离散化误差以及需要通过独立实验校验的速度内环执行误差。本文假设下层速度控制带宽足以支撑上述速度层建模。执行器集合$\mathcal U$必须包含真实线速度、角速度及其变化率限制；对于轮距为$b$的差速车辆，还可加入轮速约束

$$
|v\pm b\omega/2|\le v_{wheel,max}.
$$

上述约束均可写为线性不等式。需要指出，若安全二次规划输出后仍存在未建模的限幅或排队环节，则理论推导针对的控制输入与实际执行输入不再一致，因此这些执行约束必须在优化器内部显式建模。

本文选择低速差速车辆是为了将研究重点限定在通信时延条件下的共享控制权分配与执行安全。若进一步采用阿克曼车辆，则可令$x=(p_x,p_y,\psi,v)$、$u=(a,\delta)$并使用$\dot\psi=v\tan\delta/L$描述转向运动，但此时距离约束相对于加速度和转角可能具有更高相对阶，且$\tan\delta$会引入额外非线性。因此，下文理论结论不直接外推至高速阿克曼车辆。

在预测时域内，车端分别获得人工候选控制序列$u_i^H$与自主候选控制序列$u_i^A$。定义$\alpha_i\in[0,1]$为自主控制权，其中$\alpha_i=0$表示完全采用人工候选输入，$\alpha_i=1$表示完全采用自主候选输入。本文的目标不是预先规定$\alpha_i$与时延或风险的函数关系，而是在未来安全约束下求解整个控制权序列$\boldsymbol\alpha$。

### 轨迹与不确定性定义

本文在当前车端状态上分别定义四类未来轨迹。驾驶员反事实意图位置分布记为$P_i^H\sim(\mu_i^H,\Sigma_i^H)$，用于描述若驾驶员候选策略从当前车辆状态继续执行时车辆可能希望到达的位置；本地自动驾驶规划位置记为$p_i^A$；给定实际共享控制策略后的执行位置分布记为$P_i^E\sim(\bar p_i,\Sigma_i^E)$；第$j$个动态障碍物的未来位置分布记为$O_{j,i}\sim(\mu_{j,i}^O,\Sigma_{j,i}^O)$。其中，$\Sigma_i^H$表示驾驶员意图预测的不确定性，而$\Sigma_i^E$描述实际共享策略执行后的状态误差，两者具有不同概率语义，不得互换。

在此基础上，本文研究如下控制问题：在当前信息集合$\mathcal F_k$给定的条件下，利用因果对齐的人工历史、本地自主规划和动态障碍物预测构造有限时域安全约束，求得满足车辆动力学、执行器与概率安全约束的最低必要自主控制权序列；随后将首个共享名义命令送入独立安全过滤器，在上层预测失配时对即将执行的控制进行最小必要修正。

## 所提方法

### 因果对齐的意图表示与统一预测风险管

本文不限定人工意图预测器的具体网络结构。预测器以因果对齐历史$\mathcal H_k$、任务目标和人工信息年龄为条件，给出未来人工候选控制或位置概率分布。若预测结果从历史观测时刻展开，则必须覆盖人工信息年龄与预测时域，并在获得未来候选策略后从当前车端状态重新积分可执行的人工反事实轨迹。由于车辆动力学一般为非线性，实际共享执行轨迹不能通过人工轨迹和自主轨迹的逐点线性插值得到，即

$$
X_E(\boldsymbol\alpha)\ne(1-\boldsymbol\alpha)X_H+\boldsymbol\alpha X_A.
\tag{4}
$$

因此，本文只在控制输入层混合人工与自主候选控制，并通过车辆模型重新展开共享执行轨迹。

为统一描述意图、执行和障碍物未来分布，定义位置置信椭圆

$$
\mathcal E(\mu,\Sigma,\beta)=\{p:(p-\mu)^\top\Sigma^{-1}(p-\mu)\le\beta^2\}.
\tag{5}
$$

其中，$\mu$和$\Sigma$分别为位置分布均值和协方差，$\beta$决定置信水平。对于二维高斯位置分布，置信度为$1-\varepsilon$的椭圆可取$\beta=\sqrt{\chi^2_{2,1-\varepsilon}}$。当协方差秩亏时，置信集合应在协方差支撑子空间内定义，或引入具有明确物理意义的估计噪声下限。需要强调，各离散预测时刻的置信椭圆串联仅构成离散置信管，并不能自动视为整条连续曲线或完整任务期间的同时置信区域。

在共同未来绝对时间网格上，本文将人工意图置信区域、自主规划位置、共享执行置信区域、障碍物置信区域、人机未来分歧、意图模糊度以及不同控制策略对应的安全裕量组织为预测风险管

$$
\mathscr T_k=\{\mathcal E^H_i,\,p^A_i,\,\mathcal E^E_i(\boldsymbol\alpha),\,
\mathcal E^O_{j,i},\,C_i,U_i,\ell^H_{j,i},\ell^A_{j,i},\ell^E_{j,i}(\boldsymbol\alpha)\}_{i=1:N,j=1:M}.
\tag{6}
$$

这里的“统一”仅表示所有变量采用相同时间轴、坐标系、物理单位和风险预算，而不是将时延、冲突和概率方差人为压缩为一个经验风险分数。

为了区分真正的人机未来空间分歧与人工意图预测本身的模糊性，令$D_p=\operatorname{diag}(L_x,L_y)$为固定且具有物理意义的位置归一化尺度，定义

$$
C_i=\|D_p^{-1}(\mu^H_i-p^A_i)\|^2,\quad
U_i=\operatorname{tr}(D_p^{-1}\Sigma^H_iD_p^{-\top}),\quad
\bar C=\sum_iw_iC_i,\quad \bar U=\sum_iw_iU_i,
\quad w_i\ge0,\ \sum_iw_i=1.
\tag{7}
$$

并有如下严格分解关系：

$$
\mathbb E\|D_p^{-1}(P^H_i-p^A_i)\|^2=C_i+U_i.
\tag{8}
$$

式(8)说明，若直接以人工概率轨迹相对于自主规划的期望平方距离作为“人机冲突”，则会把人工意图预测方差一并解释为人机意见对立。本文因此分别保留$C_i$和$U_i$：前者刻画人工均值轨迹与自主规划之间的空间分歧，后者刻画驾驶员意图本身的预测模糊度。它们可用于分析和次级偏好设计，但不会被简单映射为控制权。

### 概率安全裕量与控制权可行性

对于第$i$个预测步和第$j$个障碍物，令相对位置随机变量为$Z=P_i^E-O_{j,i}$，其均值与协方差写为

$$
\mu_Z=\bar p_i-\mu^O_{j,i},\quad
\Sigma_Z=\Sigma^E_i+\Sigma^O_{j,i}-\Sigma^{EO}_{j,i}-(\Sigma^{EO}_{j,i})^\top.
\tag{9}
$$

只有在适当条件独立时才能忽略交叉协方差$\Sigma_{j,i}^{EO}$。当交叉相关性未知时，沿任意固定方向可采用$\sigma_{rel}\le\sigma_E+\sigma_O$的保守标准差界，而不能无依据地使用方差平方和。对驾驶员反事实轨迹的风险评估只需在式(9)中将执行分布$E$替换为人工意图分布$H$。

针对动态障碍风险，理论上可以采用半空间机会约束、条件风险价值或直接碰撞概率三类形式。直接碰撞概率$\Pr(\|Z\|\le R_j)$具有最直接的几何意义，但对于一般协方差、非凸障碍物及多模态预测通常需要积分或采样，实时梯度计算代价较高。条件风险价值能够刻画尾部损失，但通常需要更复杂的尾部积分或样本辅助变量。相比之下，半空间机会约束在法向和协方差上界固定后可转化为仿射安全条件，同时具有明确概率含义，因此本文采用该方案作为主风险约束。

给定由当前信息确定并在该次优化中固定的单位分离方向$n$，要求车辆与障碍物包围半径及基础间距之和$R_j$满足

$$
\Pr(n^\top Z\ge R_j)\ge1-\varepsilon_{j,i}
\Longleftrightarrow
\ell^E_{j,i}=n^\top(\bar p_i-\mu^O_{j,i})-R_j-\kappa_{j,i}\sigma^E_{rel,j,i}\ge0,
\quad \kappa_{j,i}=\Phi^{-1}(1-\varepsilon_{j,i}).
\tag{10}
$$

其中，$\varepsilon_{j,i}$为该障碍—预测步的风险预算，$\kappa_{j,i}=\Phi^{-1}(1-\varepsilon_{j,i})$，$\sigma^E_{rel,j,i}$为相对位置沿$n$方向的标准差。所有距离均以米为单位，$\sigma^E_{rel,j,i}$同样为米，而$\kappa_{j,i}$无量纲，因此不能将方差$n^\top\Sigma n$直接与安全距离相加。由于$\|Z\|\ge n^\top Z$，式(10)对圆形避障提供的是保守充分条件，而不是与圆形碰撞概率完全等价的变换。其优势在于：固定法向与协方差上界后，安全条件能够保持为关于预测位置的仿射约束，适合实时控制权优化。

作为备选风险度量，条件风险价值的上尾定义为

$$
\operatorname{CVaR}_{1-\varepsilon}(L)
=\min_\eta\left[\eta+\varepsilon^{-1}\mathbb E(L-\eta)_+\right].
\tag{11}
$$

对于$L\sim\mathcal N(\mu_L,\sigma_L^2)$，其闭式值为$\mu_L+\sigma_L\phi(\Phi^{-1}(1-\varepsilon))/\varepsilon$；若采用样本近似，则需要为每个障碍物、预测步和样本引入附加变量，因此本文不将其作为主在线约束。经验样本可行也不能自动等价于总体风险被严格控制。

若不接受高斯假设而仅能保证均值和方差有效，可使用Cantelli不等式对应的保守系数$\kappa=\sqrt{(1-\varepsilon)/\varepsilon}$替代高斯分位数，但由此获得的边界通常更保守。对于多模态意图或障碍物轨迹，也不能在没有额外说明的情况下直接进行单高斯矩匹配并保留原概率解释；更严格的处理方式是对不同模式分别施加约束或显式分配模式风险预算。本文主推导因此限定在短时单峰或经验证可由单高斯近似的预测场景。

预测风险管可以进一步报告$\ell^H_{j,i}$、$\ell^A_{j,i}$、$\ell^E_{j,i}$、最小安全裕量及首个负裕量出现时刻。若为了绘图构造$r_{j,i}=[-\ell_{j,i}/L_r]_+$，该量只能解释为无量纲风险不足量，不能表述为真实碰撞概率。

若全部离散预测约束在当前信息条件下有效，则可由并集界得到

$$
\Pr\{\forall i,j:\|P^E_i-O_{j,i}\|\ge R_j\mid\mathcal F_k\}
\ge1-\sum_{i,j}\varepsilon_{j,i}.
\tag{12}
$$

该结论不要求时间步之间或障碍物之间相互独立，但仅表示当前固定预测策略和离散预测时域内的条件概率下界，不能直接解释为整个闭环任务无限时域的无碰撞保证。

### 最低必要自主介入的控制权序列优化

在每个优化周期内冻结人工与自主候选输入，记$d_i=u_i^A-u_i^H$，则共享输入为

$$
u_i=u^H_i+d_i\alpha_i,\qquad 0\le\alpha_i\le1.
\tag{13}
$$

在上一条可行轨迹附近对车辆模型进行局部线性化，

$$
x_{i+1}=A_ix_i+B_iu_i+c_i,\qquad x_0=\hat x_k.
\tag{14}
$$

对于本文采用的差速运动学模型，预测间隔为$\Delta$时，其线性化矩阵为

$$
A_i=\begin{bmatrix}1&0&-\Delta\bar v_i\sin\bar\psi_i\\0&1&\Delta\bar v_i\cos\bar\psi_i\\0&0&1\end{bmatrix},
\quad B_i=\begin{bmatrix}\Delta\cos\bar\psi_i&0\\\Delta\sin\bar\psi_i&0\\0&\Delta\end{bmatrix},
\quad c_i=f_\Delta(\bar x_i,\bar u_i)-A_i\bar x_i-B_i\bar u_i.
\tag{15}
$$

消去状态和输入后，预测位置可以表示为控制权序列的仿射函数

$$
\mathbf p=\mathbf p^H_{lin}+S\boldsymbol\alpha,
\qquad S_{i\ell}=C_pA_{i-1}\cdots A_{\ell+1}B_\ell d_\ell\quad(\ell<i),
\tag{16}
$$

其中，$C_p$用于提取车辆位置，$S_{i\ell}$描述第$\ell$步控制权改变对第$i$步预测位置的影响。由式(10)与式(16)，每个预测安全裕量进一步写为

$$
\ell^E_{j,i}(\boldsymbol\alpha)=b_{j,i}+g_{j,i}^\top\boldsymbol\alpha,\quad
g_{j,i,\ell}=n_{j,i}^\top S_{i\ell}.
\tag{17}
$$

其中，$g_{j,i,\ell}$具有“米/单位控制权”的直接物理意义。若$g_{j,i,\ell}>0$，则第$\ell$步增加自主控制权有助于改善第$i$步相对于障碍$j$的安全裕量；若该值小于零，则该步增加自主权反而恶化相应未来安全约束。因此，本文不预设“风险越高自主权越高”，而是由未来轨迹几何及两种候选控制的实际作用方向决定介入是否有效。

将车辆执行器限制、输入变化率、控制权边界、控制权变化率、可行驶凸走廊、概率安全裕量以及局部线性化可信域共同构成控制权可行域$\mathcal A_k$：

$$
\begin{aligned}
&u_i\in\mathcal U,\qquad u_i-u_{i-1}\in\Delta\mathcal U,\\
&0\le\alpha_i\le1,\qquad |\alpha_i-\alpha_{i-1}|\le\dot\alpha_{max}\Delta_i,\\
&H_ix_i\le h_i,\qquad \ell^E_{j,i}(\boldsymbol\alpha)\ge b_{collab,j,i},\\
&\|x_i-\bar x_i\|_\infty\le r_x,\quad\|u_i-\bar u_i\|_\infty\le r_u.
\end{aligned}
\tag{18}
$$

其中，$b_{collab,j,i}\ge0$表示协同层为安全过滤器预留的裕量，最简实现可取零。若引入与驾驶员信息年龄相关的额外裕量，应明确将其解释为协同层的保守预留，而非物理上必需的碰撞距离。第一步输入变化率必须相对于上一周期的实际执行命令$u^F_{k-1}$计算；若预测间隔$\Delta$大于实际控制周期$T_s$，第一步控制权速率约束仍应使用$T_s$，避免错误放大允许的瞬时权重变化。

若采用常规单目标形式，次级性能可以写为

$$
\begin{aligned}
J=&\sum_{i=0}^{N-1}\frac{\Delta_i}{T_H}
\left[w_a\alpha_i^2+w_s\left(\frac{\alpha_i-\alpha_{i-1}}{\dot\alpha_{ref}\Delta_i}\right)^2
w_u\|D_u^{-1}(u_i-u_i^H)\|^2\right]\\
&+\sum_{i=1}^{N}w_i\left[w_H\|D_p^{-1}(p_i-\mu_i^H)\|_{W_i}^2
w_P\|D_p^{-1}(p_i-p_i^{task})\|_{Q_P}^2\right],
\end{aligned}
\tag{19}
$$

其中，$D_u=\operatorname{diag}(v_{ref},\omega_{ref})$用于归一化不同量纲的控制输入；$W_i=(I+D_p^{-1}\Sigma_i^H D_p^{-\top})^{-1}$在驾驶员意图较模糊的方向减小偏好保持惩罚，但不降低物理安全要求；$p_i^{task}$为任务走廊或局部目标参考。式(19)各项分别描述控制源权重、控制权变化平滑性、相对人工候选输入的修改、相对驾驶员预测意图的偏离以及任务轨迹性能。

需要注意，对于固定的$\Sigma_i^H$，有$\mathbb E\|p_i-P_i^H\|_Q^2=\|p_i-\mu_i^H\|_Q^2+\operatorname{tr}(Q\Sigma_i^H)$，其中迹项相对于控制决策是常数。因此，仅把该期望平方误差写进目标函数并不能自动获得真正的“不确定性感知”优化性质。

然而，单纯通过在式(19)中给$\alpha_i$设置较大惩罚权重，并不能严格保证最低必要自主介入，因为轨迹性能项仍可能以增加自主权换取更低总代价。为此，本文采用两级词典序优化。第一级仅在可行域内最小化预测时域中的累计自主控制权：

$$
A_k^*=\min_{\boldsymbol\alpha\in\mathcal A_k}
I_\alpha(\boldsymbol\alpha),\qquad
I_\alpha=\sum_{i=0}^{N-1}\frac{\Delta_i}{T_H}\alpha_i.
\tag{20}
$$

其中，$T_H$为预测时域总长度。随后在第一级得到的最低介入预算基础上求解

$$
\min_{\boldsymbol\alpha\in\mathcal A_k}J_{secondary}(\boldsymbol\alpha)
\quad\text{s.t.}\quad I_\alpha\le A_k^*+\delta_\alpha.
\tag{21}
$$

其中，$J_{secondary}$保留式(19)中的控制权平滑、人工输入修改、意图轨迹保持和必要任务性能项，也可以附加很小的$\|\boldsymbol\alpha\|^2$项以获得唯一解。$\delta_\alpha=0$对应严格的词典序最小介入，小的正值则表示允许在可明确报告的额外自主权预算内改善次级性能。最小化$\sum_i\alpha_i$与最小化$\sum_i\alpha_i^2$具有不同意义：前者优先减少累计控制源权重，后者则倾向于将介入分散到更多预测步。实际控制修改量也不等价于控制权，因为$u_i-u_i^H=d_i\alpha_i$；当$u_i^H=u_i^A$时，$\alpha_i$甚至无法从实际车辆行为中辨识，只能被视为内部控制权记账量。

**命题1（凸性与最低介入性质）.** 若人工与自主候选输入、局部线性模型、分离法向、协方差上界及可行驶走廊均在求解前固定，式(19)中的二次权重均为半正定，并且$\mathcal A_k$非空，则式(20)为线性规划，式(21)为凸二次规划，其输出满足$I_\alpha\le A_k^*+\delta_\alpha$。进一步地，当$\delta_\alpha=0$且全零控制权序列可行时，最优控制权序列必为全零。

**证明.** 式(13)–(18)中的车辆动力学、混合输入、输入边界、控制权边界、走廊与固定法向机会约束均为仿射等式或线性不等式，因此$\mathcal A_k$为凸多面体。式(19)是仿射变量上的正半定二次型之和，故为凸函数。式(20)的目标$I_\alpha$为线性函数，因此第一级为线性规划；式(21)增加线性预算约束后仍为凸二次规划。由$\alpha_i\ge0$及$\Delta_i/T_H>0$可得

$$
I_\alpha\ge0,\qquad I_\alpha=0\Longleftrightarrow\alpha_i=0,\ \forall i.
$$

若全零序列属于$\mathcal A_k$，则第一级最优值$A_k^*=0$；当$\delta_\alpha=0$时，第二级预算约束迫使$I_\alpha=0$，从而所有$\alpha_i=0$。证毕。需要指出，若上一周期已经存在较高自主权，硬控制权变化率约束可能使全零序列暂时不可行，因此“未来风险消失”并不意味着系统能够瞬时恢复到完全人工控制。

**命题2（固定预测条件下的保守度单调性）.** 若仅通过增大置信距离或收紧其他安全约束使可行域由$\mathcal A_k$缩小为$\mathcal A_k'\subseteq\mathcal A_k$，同时保持预测均值、候选输入、分离法向和其他参数不变，且两个可行域均非空，则相应的最低自主权预算满足$A_k^{*\prime}\ge A_k^*$。

**证明.** $A_k^*$是在$\mathcal A_k$上的最小值，而$\mathcal A_k'$是其子集。在较小可行集合上对同一目标函数进行最小化，其最优值不可能小于原集合上的最优值，因此结论成立。证毕。该命题只说明在其他条件冻结时，安全约束收紧不会降低累计最低自主权，并不意味着实际网络时延增大时每一步$\alpha_i$必然增大，因为时延同时可能改变预测均值、规划路线和介入方向的有效性。

对于活跃安全约束，还可以通过标准优化敏感度分析读取对偶乘子。若安全约束写为$G\boldsymbol\alpha\ge b$，则在常规正则条件下，对偶乘子刻画第一级最优介入预算对相应安全阈值的局部敏感度，可用于解释某一时刻自主介入主要由哪些未来风险约束驱动；该性质属于标准凸优化解释工具，而不是本文单独声称的新理论。

### 非凸性、无解与顺序凸近似

原始非线性车辆动力学、圆形避障几何、依赖决策的协方差以及同步重规划自主候选控制都会使完整问题成为非凸优化。为满足实时实现要求，本文采用一次顺序凸化：移位上一周期的可行解作为线性化参考，冻结人工/自主候选输入、分离法向和协方差上界，并设置状态与控制可信域后求解式(20)–(21)。计算预算允许时，可追加一次重新线性化，但本文不通过大量离线迭代获得结果后再宣称实时性。因此，式(20)–(21)得到的是当前局部凸近似问题的最优控制权，而不是原始非线性问题的全局最优解。

$\mathcal A_k$可能为空，例如人工与自主候选控制同时指向危险区域、固定绕障侧选择错误，或标量控制权混合无法同时产生所需制动与转向。在这种情况下，上层协同计划应在该周期判定为不可行，并将名义控制交给独立安全层或平台后备流程处理，而不是通过松弛硬安全约束继续宣称安全。另一种可能的控制结构是自由优化$u_i$并写为$u_i=u_i^H+d_i\alpha_i+r_i$，但只要$r_i\neq0$，$\alpha_i$就不再完整表示自主介入，且分解可能不唯一。因此，本文在常态协同层坚持$r_i=0$，仅允许最后安全过滤器在必要时离开人工—自主候选输入的混合线段。

### 信息年龄与不确定性感知的独立安全过滤

上层预测安全约束用于提前决定控制权，但其有效性仍依赖人工意图、障碍预测和局部模型。为使执行安全不依赖于特定人工意图预测器，本文在车端实际执行入口设置独立安全过滤器。该过滤器不使用$\mu_i^H$、$\Sigma_i^H$或任何特定延迟补偿预测器输出，而只依据车端实际可获得的相对状态、障碍运动估计、信息年龄以及经独立验证的模型和执行误差界。

一种直观的时延扩张安全距离可写成

$$
d_{eff}=d_0+v_{rel}\tau+\tfrac12a_{max}\tau^2+\kappa\sigma_{rel}
\tag{22}
$$

但该式只有在明确相对运动界、信息年龄和不确定性来源后才能作为保守距离解释，本身不能直接推出安全集合前向不变性。为此，本文从具有时间戳的相对状态传播出发。设共同时间戳$s$上的相对位置和速度满足

$$
r(s)=\hat r_s+e_p,\qquad \dot r(s)=\hat v_s+e_v,
\qquad \|\ddot r(t)\|\le\bar a_{rel}.
\tag{23}
$$

其中，$\bar a_{rel}$为相对加速度范数上界。对于信息年龄$\tau=t-s$，相对位置满足

$$
r(t)=\hat r_s+\tau\hat v_s+e_p+\tau e_v+
\int_0^\tau(\tau-z)\ddot r(s+z)\,dz.
\tag{24}
$$

若$(e_p,e_v)$为零均值联合高斯变量，其误差协方差传播为

$$
P(\tau)=P_{pp}+\tau(P_{pv}+P_{vp})+\tau^2P_{vv}.
\tag{25}
$$

结合相对加速度积分项的确定性范数上界，构造时延相关相对状态误差集合

$$
\mathcal E(\tau)=b(\tau)\mathbb B_2\oplus
\{e:e^\top P(\tau)^{-1}e\le\beta^2\},
\quad b(\tau)=\tfrac12\bar a_{rel}\tau^2+b_{clk}+b_{model}+b_{act},
\tag{26}
$$

其中，$\beta=\sqrt{\chi^2_{2,1-\delta}}$对应二维高斯误差的置信水平；$b_{clk}$、$b_{model}$与$b_{act}$分别用于覆盖时钟误差、局部模型误差与独立验证的执行误差。例如，时钟不确定性可以用最大相对速度乘以时间戳误差上界进行保守转换。各误差项必须避免重复计数：若某类随机加速度已经通过协方差传播计入$P(\tau)$，就不应再次把同一随机效应加入确定性半径$b(\tau)$。式(26)沿任意单位方向$n$的支撑函数及外接球半径为

$$
\rho(n,\tau)=\sup_{e\in\mathcal E(\tau)}n^\top e
=b(\tau)+\beta\sqrt{n^\top P(\tau)n},\qquad
\rho^{rad}(\tau)=b(\tau)+\beta\sqrt{\lambda_{max}(P(\tau))}.
\tag{27}
$$

该式给出了时延和不确定性扩大安全边界的明确运动学与概率来源。如果相对位置均值已经按$\hat r_s+\tau\hat v_s$传播，则不能再次重复加入完整的$\bar v_{rel}\tau$项。

对于速度层差速车辆，为使线速度$v$和角速度$\omega$同时进入一阶位置安全约束，定义前视点

$$
q=p+\ell[\cos\psi,\sin\psi]^\top,\quad \ell>0,
\qquad
\dot q=G(\psi)u,\quad
G(\psi)=\begin{bmatrix}\cos\psi&-\ell\sin\psi\\\sin\psi&\ell\cos\psi\end{bmatrix}.
\tag{28}
$$

由于$\det G=\ell>0$，两维速度层输入均进入前视点运动。为保证前视点安全能够保守覆盖真实车体，需要相应扩大车辆包围半径：

$$
R_j^{phys}=r_{body}+\ell+r_j^O+d_0.
\tag{29}
$$

该近似保守但几何有效。上层与下层应采用兼容的前视点和车身外包络，以避免两个层级仅因几何定义不一致而产生不必要的反复修正。若直接以车辆质心距离对$(v,\omega)$建立一阶屏障，则角速度通常不会出现在屏障的一阶导数中，因此不能为了保持二次规划形式而忽略输入相对阶问题。

### 连续时间屏障形式及离散化选择

在状态精确、控制连续更新且障碍物轨迹可微的理想情况下，可定义连续时间真实距离屏障

$$
h_j(x,t)=\|q(x)-o_j(t)\|-R_j(t),\qquad
\mathcal C(t)=\{x:h_j(x,t)\ge0,\ \forall j\}.
\tag{30}
$$

记$n_j=(q-o_j)/\|q-o_j\|$，则

$$
\dot h_j=n_j^\top(G(\psi)u-v_j^O)-\dot R_j(t).
\tag{31}
$$

若施加$\dot h_j+\lambda h_j\ge0$，在连续模型、无采样误差且约束始终可行的条件下，可以由比较引理得到$h_j(t)\ge e^{-\lambda t}h_j(0)$。然而，当安全半径$R_j(t)$包含实时变化的信息年龄、速度上界或概率不确定性时，$\dot R_j(t)$及其状态依赖导数不能被忽略；传感器更新还可能造成$R_j(t)$跳变，使连续比较证明额外需要验证跳变后安全条件。对于20–50 Hz离散控制系统，仅施加连续时间约束而忽略采样间车辆与障碍物运动，也不能据此宣称连续区间安全。

此外，有界状态或环境不确定性若直接进入$G(\psi)u$等决策相关项，鲁棒约束可能变为范数约束并形成二阶锥规划。为了保持最终安全过滤器为低维凸二次规划，并使证明与实际数字控制周期一致，本文采用下述离散鲁棒充分条件。

在离散控制周期中，首先考虑一个采样间隔内可能发生的最大相对移动，定义

$$
\bar R_j=R_j^{phys}+\bar V_jT_s,
\qquad h_j(r)=\|r\|-\bar R_j.
\tag{32}
$$

其中，$\bar V_j$为车辆前视点与障碍$j$之间相对速度的有效上界，可采用

$$
\bar V_j\le v_{max}+\ell\omega_{max}+v^O_{j,max}
$$

作为由执行器和障碍物运动界保证的保守估计。若控制周期存在抖动，则应使用最大实际命令保持间隔替代名义$T_s$。该项只用于覆盖一个数字控制采样间隔内的相对位移，不能替代真实制动动力学。对当前与下一步真实相对位置，采用

$$
r_{j,k}=\hat r_{j,k}+e_{j,k},\quad e_{j,k}\in\mathcal E_{j,k},
\qquad
r_{j,k+1}=\bar r_{j,k+1}(u)+e^+_{j,k},\quad e^+_{j,k}\in\mathcal E^+_{j,k},
\tag{33}
$$

并令下一步相对位置均值关于待执行输入保持仿射：

$$
\bar r_{j,k+1}(u)=\hat r_{j,k}+T_s[\hat G_k u-\hat v^O_{j,k}].
\tag{34}
$$

根据当前相对状态误差集合，定义真实屏障函数的上、下界

$$
H^+_{j,k}=\|\hat r_{j,k}\|+\rho^{rad}_{j,k}-\bar R_j,
\qquad
H^-_{j,k}=\|\hat r_{j,k}\|-\rho^{rad}_{j,k}-\bar R_j.
\tag{35}
$$

初始时要求$H^-_{j,0}\ge0$。在每个实际控制周期内，选取由当前信息确定的固定单位法向$n_{j,k}$，并对每个障碍施加离散鲁棒屏障充分条件

$$
n_{j,k}^\top\bar r_{j,k+1}(u)-\rho^+_{j,k}(n_{j,k})-\bar R_j
\ge(1-\gamma)H^+_{j,k},\qquad 0<\gamma\le1.
\tag{36}
$$

最后，令上层两级控制权优化得到的首个共享命令为$u_k^N$，安全过滤器在完整物理输入集合$\mathcal U_k$内求解

$$
\boxed{
u_k^F=\arg\min_{u\in\mathcal U_k}\tfrac12(u-u_k^N)^\top W_F(u-u_k^N)
\quad\text{s.t. 式(36)对所有障碍成立},\quad W_F\succ0.}
\tag{37}
$$

式(36)在误差界与法向固定后关于$u$为仿射约束，因此式(37)是一个低维凸二次规划。其目标仅最小化相对于共享名义命令的执行修改，不再承担控制权分配或自主路径优化职责。若$u_k^N$本身满足全部安全过滤约束，则由$W_F\succ0$及目标函数严格凸性可知唯一最优解为$u_k^F=u_k^N$，即安全层在无需修正时不会额外干预。

上述离散安全约束的理论性质如下。

**引理3（支撑函数下界）.** 对任意单位向量$n$，若式(33)定义的下一步误差集合有效，则由欧氏范数与集合支撑函数关系可得真实下一步屏障的下界

$$
h_j(r_{j,k+1})\ge n^\top\bar r_{j,k+1}(u)-\rho^+_{j,k}(n)-\bar R_j.
\tag{38}
$$

**证明.** 由$\|r\|\ge n^\top r$，以及式(26)的中心对称误差集合满足$n^\top e\ge-\rho(n)$，将$r_{j,k+1}=\bar r_{j,k+1}(u)+e^+_{j,k}$代入即可得到式(38)。若采用非对称误差集合，则相应支撑函数应改为$\rho(-n)$。证毕。

**命题4（置信事件上的离散前向不变性）.** 假设初始时刻对所有障碍均满足$H^-_{j,0}\ge0$；式(33)的当前与下一步误差集合在所考虑置信事件上有效；每一步安全过滤器均存在满足硬约束的控制输入并按建模要求执行。则真实安全集合$\mathcal C=\{r:h_j(r_j)\ge0,\ \forall j\}$在该置信事件上前向不变。

**证明.** 由三角不等式有$h_j(r_{j,k})\le H^+_{j,k}$。结合引理3与式(36)，得到

$$
h_j(r_{j,k+1})\ge(1-\gamma)H^+_{j,k}
\ge(1-\gamma)h_j(r_{j,k}).
\tag{39}
$$

由初始条件$H^-_{j,0}\ge0$可得$h_j(r_{j,0})\ge0$。式(39)进一步给出$h_j(r_{j,k})\ge(1-\gamma)^k h_j(r_{j,0})\ge0$，因此对所有障碍均保持非负，真实安全集合前向不变。该证明约束的是真实物理距离，而不是连续两次状态估计值之间的包含关系，因此不要求下一次滤波更新后的置信集合必须嵌套于当前集合。证毕。

**命题5（有限时域概率无碰撞下界）.** 考虑$K$个实际执行区间。若初始置信事件失败概率不超过$\delta_0$，每个时刻$k$对每个障碍$j$的联合误差界失败概率不超过$\delta_{j,k}$，且在所有这些置信事件成立的历史上安全过滤器或经认证后备控制持续可行并按时执行，同时式(32)的采样间相对运动上界成立，则由并集界得到

$$
\Pr\{\text{在}[0,KT_s]\text{全程无碰撞}\}
\ge1-\delta_0-\sum_{k=0}^{K-1}\sum_{j=1}^{M_k}\delta_{j,k}.
\tag{40}
$$

**证明.** 对所有置信事件使用条件概率的全期望关系与并集界，可以得到这些事件同时成立的概率至少为式(40)右端。该事件上，由命题4可知所有离散网格时刻的真实距离至少保持在$R_j^{phys}+\bar V_jT_s$之外。对任意$t\in[t_k,t_{k+1}]$，相对距离在一个采样周期内最多减少$\bar V_jT_s$，因此连续区间内真实车身距离仍不小于$R_j^{phys}$。该结论不要求不同时刻误差事件相互独立。证毕。

式(40)的有效性依赖于误差集合确实具有所声明的条件覆盖率。若时延上界本身仅以概率$1-\delta_\tau$成立，则右端还需进一步减去$\delta_\tau$。如果当前与下一步分别构造两个置信集合，则其失败概率预算应合并后再记入$\delta_{j,k}$，避免风险预算重复使用。尤其需要强调，“每一步95%置信”并不意味着整个任务具有95%的安全概率。若仅获得未经校准的预测网络协方差，则本文只能报告经验覆盖率和实验安全表现，不能将式(40)表述为已验证的物理概率保证。

### 安全结论的适用层级与可行性边界

本文区分确定性安全、鲁棒安全与概率安全三类结论。在模型和状态精确、硬约束始终可行且命令正确执行时，式(36)–(39)给出确定性的离散前向不变性；若状态与环境误差属于始终有效的有界支撑集合，则得到对这些误差集合内全部扰动成立的鲁棒前向不变性；若误差集合仅以给定概率覆盖真实误差，则只能得到类似式(40)的有限时域概率下界。若只有神经网络输出协方差而缺乏独立校准，则不能将经验不确定度直接升级为概率安全保证。

有界通信时延、当前未碰撞以及有效置信区间均不能单独保证式(37)始终可行。动态障碍物可能封堵所有方向，车辆也可能由于执行器制动能力不足而已经进入不可恢复状态。因此，本文最严格的理论表述是：在声明的初始安全集、误差界及持续可行条件下，安全过滤器满足上述前向不变性和有限时域概率安全性质。若需要去除这一条件性可行假设，则必须进一步构造经认证的后备控制不变集$\mathcal C_B$并证明递归可行性；简单发送零速度并不能保证动态障碍物不会撞向静止车辆。

若安全过滤器之后还存在显著网络或执行器排队时延，则应将输入队列和执行器动态增广进状态，并在控制真正生效时刻重新建立屏障条件；仅在安全距离中增加$v\tau$而继续使用无输入时延模型中的$G(\psi)u$并不足以构成严格证明。本文因此将最终过滤器放置于车端执行入口，并只允许剩余本地时延由经验证的短时执行误差界$b_{act}$覆盖。

### 双层协同与执行安全的职责分离

上层控制权优化和底层安全过滤虽然都包含安全约束，但具有不同作用域。前者在未来有限时域内利用因果对齐意图、本地自主轨迹和动态障碍预测进行主动协同，其决策受限于人工与自主候选输入构成的混合线段，回答“何时应介入以及最低需要多少自主权”；后者只审查即将执行的首个名义命令，允许在完整物理输入集合中寻找安全控制，回答“该命令在当前车端信息和误差界下能否安全执行”。

若共享名义命令$u_k^N$已经满足式(37)的全部硬约束，则由于$W_F\succ0$且目标函数在$u=u_k^N$处达到唯一零值，可得$u_k^F=u_k^N$。因此，底层过滤器具有严格的“不需要修改时不修改”性质。若过滤器长期频繁或大幅修正上层命令，则说明上层预测模型、两层几何定义、风险预算或候选控制存在失配，这一现象应被视为系统诊断信号，而不能简单解释为安全层“更有效”。

安全过滤器的理论独立性具体表现为：其硬可行集合与安全证明不依赖$\mu_i^H$、$\Sigma_i^H$或任何特定意图模型结构，人工意图只通过名义命令$u_k^N$影响式(37)的最小修改目标。因此，驾驶员意图方差不直接进入底层硬安全边界；如果某种实现确实保留了随机人工控制通道，则必须先建立该随机控制策略到实际执行状态误差的传播关系，之后才能将相应不确定性纳入安全集合。

### 计算结构与在线实现

固定状态维度时，式(10)涉及的全部障碍风险投影计算量约为$O(NM)$，控制权敏感度矩阵$S$具有下三角结构，其显式构建复杂度约为$O(N^2)$乘以固定小状态维度。消元后的控制权优化主要包含$N$个控制权变量及$O(NM)$个安全约束；最后安全过滤器只有$v$和$\omega$两个决策变量，每个障碍对应一个主要安全约束。因此，该结构适合采用稀疏凸优化求解器、预分配矩阵和上一周期解热启动实现在线计算。

需要强调，上述问题规模只能说明实时实现具有合理可行性，并不能替代真实硬件的墙钟耗时验证。实际系统应分别记录预测更新、问题组装、两级优化与安全过滤的求解耗时，并报告中位数、高分位耗时、最大耗时和控制截止期错失率。若意图预测模型更新频率低于控制回调频率，则控制线程不应等待预测网络，而应继续使用最近预测并根据其信息年龄传播不确定性。

## 结论与展望

本文面向具有通信时延的低速远程移动车辆共享控制问题，围绕“驾驶员信息陈旧条件下何时需要车端自主介入，以及最低需要多少介入”建立了一套因果对齐、预测协同与独立安全过滤相结合的方法框架。与依据当前人机输入差异、时延大小或经验风险指标直接映射控制权的方案不同，本文首先在共同未来时间基准上明确区分驾驶员反事实意图、自主规划、共享执行和动态障碍物预测，并分别建模人机未来空间分歧、意图模糊度和具有概率含义的安全裕量；随后通过局部线性化将未来安全约束转化为控制权可行域，并采用两级优化显式求得最低累计自主权预算及其对应的平滑控制权序列。进一步地，本文在车端执行入口建立与人工意图模型解耦的信息年龄与不确定性感知安全过滤器，在明确的置信事件、初始安全和持续可行条件下给出真实安全集合的离散前向不变性与有限时域概率安全边界。

本文的理论设计刻意限定了方法能够支持的结论范围。首先，本文当前采用低速差速车辆速度层模型，以避免高速阿克曼车辆中的轮胎动力学、输入相对阶和执行器动态显著扩大理论范围，因此相关结论不能直接外推至高速公路远程驾驶。其次，概率安全约束依赖意图、执行与障碍预测分布的有效统计建模和置信覆盖率；对于多模态意图、严重域偏移或未经校准的协方差，本文的概率结论需要相应收缩为经验性能评价。再次，上层控制权优化的凸性建立在每周期冻结候选输入、分离法向和协方差上界并采用局部线性模型的条件下，得到的是顺序凸化后的局部优化结果，而非原始非线性共享控制问题的全局最优解。最后，安全过滤器的前向不变性结论以约束持续可行为前提；若动态环境使全部安全控制方向均不可达，则需要更强的认证后备集合或递归可行性设计，而不能仅依赖停车命令获得无条件安全保证。

后续工作将首先通过仿真和人机在回路实验验证本文三部分设计的独立作用，包括比较因果对齐多步风险与瞬时风险指标的介入提前性、比较词典序最低自主预算与启发式或普通加权优化的控制权使用效率，以及在相同名义命令条件下评价信息年龄/不确定性安全过滤器对动态障碍和网络异常的鲁棒性。在完成低速平台验证后，可进一步研究面向阿克曼车辆的高相对阶安全约束、非高斯或多模态轨迹的风险预算分配、控制权优化与自主局部规划的联合设计，以及能够显式保证安全过滤器递归可行性的后备控制集合，从而扩大该框架在真实远程驾驶系统中的适用范围。
